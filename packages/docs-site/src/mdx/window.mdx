# Window & Dialog

窗口是 Win95 的灵魂：标题栏渐变、控制按钮像素图标、状态栏。

## 无障碍

| 模式 | 实现 |
|------|------|
| 焦点陷阱 | `useFocusTrap`（Tab 循环 + 恢复焦点） |
| 模态 | `aria-modal="true"` |
| 关闭 | Esc / 标题栏 Close / OK / Cancel |
| 名称 | `aria-labelledby` 指向标题 |
