<script setup>
import { ref } from "vue";
import {
  W95Window,
  W95Dialog,
  W95Button,
  W95StatusBar,
  W95StatusBarField,
  W95Accordion,
  W95AccordionItem,
} from "vue-win95";

const open = ref(false);
const acc = ref("a");
</script>

# Window / Dialog / Accordion

## Window

标题栏渐变 + 控制按钮 + 可选状态栏。

<div class="demo">
  <div class="demo-label">WINDOW + STATUS BAR</div>
  <W95Window title="Task Manager" :width="400" show-minimize show-maximize @close="() => {}">
    <p style="font-size:14px;margin:0 0 10px">Processes are running smoothly.</p>
    <W95Button @click="open = true">Open Dialog</W95Button>
    <template #status>
      <W95StatusBarField>Press F1 for help</W95StatusBarField>
      <W95StatusBarField>CPU: 14%</W95StatusBarField>
    </template>
  </W95Window>
</div>

### API — `W95Window`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `title` | `string` | `""` | 标题栏文字 |
| `active` | `boolean` | `true` | true=蓝渐变，false=灰渐变 |
| `showMinimize` | `boolean` | `true` | 显示最小化 |
| `showMaximize` | `boolean` | `true` | 显示最大化 |
| `showClose` | `boolean` | `true` | 显示关闭 |
| `width` | `number \| string` | — | 窗口宽度 |

| Event | 说明 |
|-------|------|
| `minimize` / `maximize` / `close` | 标题栏按钮 |

| Slot | 说明 |
|------|------|
| default | 窗体内容 |
| `status` | 底部状态栏 |

### API — `W95StatusBar` / `W95StatusBarField`

| 组件 | Prop | 说明 |
|------|------|------|
| `W95StatusBar` | — | 状态栏容器 `role=status` |
| `W95StatusBarField` | `grow?: boolean`（默认 true） | 单个状态格 |

---

## Dialog

模态框：焦点陷阱、Esc、OK/Cancel。

<div class="demo">
  <div class="demo-label">DIALOG</div>
  <W95Button @click="open = true">Open Dialog</W95Button>
  <W95Dialog
    v-model="open"
    title="Confirm"
    :width="520"
    @confirm="open = false"
    @cancel="open = false"
  >
    <p style="font-size:14px;margin:0">Are you sure you want to continue?</p>
  </W95Dialog>
  <p style="color:#fff;font-size:13px;margin:8px 0 0">
    Esc / OK / Cancel / 标题栏 Close 均可关闭。
  </p>
</div>

### API — `W95Dialog`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `boolean` | — | 是否打开（v-model）**必填** |
| `title` | `string` | `"Dialog"` | 标题 |
| `width` | `number \| string` | `480` | 宽度 |
| `showClose` | `boolean` | `true` | 标题栏关闭按钮 |
| `closeOnOverlay` | `boolean` | `true` | 点击遮罩关闭 |

| Event | 说明 |
|-------|------|
| `update:modelValue` | `boolean` |
| `confirm` / `cancel` / `close` | 确认 / 取消 / 关闭 |

| Slot | 说明 |
|------|------|
| default | 正文 |
| `footer` | 自定义底部按钮 |

无障碍：`role="alertdialog"`、`aria-modal`、文档级 Esc。

## Accordion

<div class="demo">
  <div class="demo-label">ACCORDION</div>
  <W95Accordion v-model="acc" style="max-width:360px">
    <W95AccordionItem value="a" title="General">System settings.</W95AccordionItem>
    <W95AccordionItem value="b" title="Appearance">Theme options.</W95AccordionItem>
    <W95AccordionItem value="c" title="Advanced">
      Power user options.
      <template #title>Advanced (custom)</template>
    </W95AccordionItem>
  </W95Accordion>
</div>

### API — `W95Accordion`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `string \| number \| null` | `null` | 打开项 id（v-model）；再点同一项可关闭 |

### API — `W95AccordionItem`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `value` | `string \| number` | — | **必填**，项 id |
| `title` | `string` | `""` | 标题文案 |

| Slot | 说明 |
|------|------|
| default | 展开内容 |
| `title` | 自定义标题 |

`aria-expanded` + `role="region"`。
