# Button

命令按钮，还原 Win95 凸起 / 凹陷边框与默认按钮加粗描边。

<div class="demo">
  <div class="demo-label">STATES</div>
  <div style="display:flex;gap:8px;flex-wrap:wrap;align-items:center">
    <W95Button>Normal</W95Button>
    <W95Button default>Default</W95Button>
    <W95Button disabled>Disabled</W95Button>
    <W95Tooltip content="This is the default action">
      <W95Button default>Hover me</W95Button>
    </W95Tooltip>
  </div>
</div>

## API

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `type` | `button\|submit\|reset` | `button` | 原生 type |
| `default` | `boolean` | `false` | 默认按钮描边 |
| `disabled` | `boolean` | `false` | 禁用 |
| `block` | `boolean` | `false` | 块级宽度 |

## 无障碍

- 使用语义化 `<button>`
- 焦点环为 Win95 点状虚线（`.w95-focus`）
