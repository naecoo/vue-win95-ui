<script setup>
import { ref } from "vue";
import {
  W95Button,
  W95Checkbox,
  W95Radio,
  W95RadioGroup,
  W95Switch,
  W95Avatar,
  W95Divider,
  W95Tooltip,
} from "vue-win95";

const pb = ref("smooth");
const agree = ref(true);
const sound = ref(false);

# Button & 基础控件

命令按钮与简单状态控件。边框使用 Win95 双层 `inset` 阴影。

## Button

<div class="demo">
  <div class="demo-label">BUTTON STATES</div>
  <div style="display:flex;gap:8px;flex-wrap:wrap;align-items:center">
    <W95Button>Normal</W95Button>
    <W95Button default>Default</W95Button>
    <W95Button disabled>Disabled</W95Button>
    <W95Button block style="max-width:160px">Block</W95Button>
    <W95Tooltip content="Hover tooltip">
      <W95Button default>+ Tooltip</W95Button>
    </W95Tooltip>
  </div>
</div>

### API — `W95Button`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `type` | `button \| submit \| reset` | `button` | 原生 type |
| `default` | `boolean` | `false` | 默认按钮（加粗描边） |
| `disabled` | `boolean` | `false` | 禁用 |
| `block` | `boolean` | `false` | 宽度 100% |
| `class` | `string` | — | 追加 class |

| Event | Payload | 说明 |
|-------|---------|------|
| `click` | `MouseEvent` | 未禁用时触发 |

| Slot | 说明 |
|------|------|
| default | 按钮文案 |

## Checkbox

<div class="demo">
  <div class="demo-label">CHECKBOX</div>
  <div style="display:flex;flex-direction:column;gap:6px">
    <W95Checkbox v-model="agree" label="I have read the agreement" />
    <W95Checkbox :model-value="true" label="Checked" />
    <W95Checkbox disabled label="Disabled" />
    <W95Checkbox :model-value="true" disabled label="Disabled + checked" />
  </div>
</div>

### API — `W95Checkbox`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `boolean` | `false` | 选中态（v-model） |
| `label` | `string` | 空 | 标签文本 |
| `disabled` | `boolean` | `false` | 禁用 |
| `id` | `string` | 自动 | 关联 label |
| `name` / `value` | — | — | 原生表单字段 |

| Event | Payload |
|-------|---------|
| `update:modelValue` | `boolean` |
| `change` | `boolean` |

## Radio / RadioGroup

<div class="demo">
  <div class="demo-label">RADIO GROUP</div>
  <W95RadioGroup v-model="pb" legend="Peanut butter" name="pb">
    <W95Radio value="smooth" label="Should be smooth" />
    <W95Radio value="crunchy" label="Crunchy is good" />
    <W95Radio value="na" label="N/A" disabled />
  </W95RadioGroup>
  <p style="color:#fff;font-size:13px;margin:8px 0 0">value = {{ pb }}</p>
</div>

### API — `W95RadioGroup`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `string \| number \| boolean` | — | 选中值（v-model） |
| `legend` | `string` | 空 | fieldset 图例 |
| `name` | `string` | 自动 | 原生 name |
| `disabled` | `boolean` | `false` | 整组禁用 |

### API — `W95Radio`

| Prop | Type | 说明 |
|------|------|------|
| `value` | `string \| number \| boolean` | **必填**，选项值 |
| `label` | `string` | 标签 |
| `disabled` | `boolean` | 禁用 |
| `modelValue` | 同上 | 独立使用时的选中值 |

Group 内 Radio 通过 provide/inject 自动同步；无障碍角色为 `radiogroup`。

## Switch

<div class="demo">
  <div class="demo-label">SWITCH</div>

    <W95Switch v-model="sound" label="Sound" />

### API — `W95Switch`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `boolean` | `false` | 开关态（v-model） |
| `label` | `string` | 空 | 标签 |
| `disabled` | `boolean` | `false` | 禁用 |

角色：`role="switch"` + `aria-checked`。
