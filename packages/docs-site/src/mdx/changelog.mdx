# Changelog

本项目遵循 Keep a Changelog 风格，版本号遵循 SemVer。

## 0.2.0 — 2026-09-17

### Added
- **基础**：Button, Input, Checkbox, Radio/RadioGroup, Select, Slider, ProgressBar, GroupBox, FieldRow, Divider, StatusBar
- **容器**：Window, Dialog（焦点陷阱）, Tabs, Menu/MenuBar, Toolbar, Tree, Splitter, Accordion
- **浮层**：Tooltip, Toast, Dropdown, ComboBox
- **数据**：Table, SpinButton, DatePicker, Breadcrumb, Pagination, Switch, Avatar
- **工程**：`@win95/tailwind-preset`、内置 Pixelated MS Sans Serif、`cn()` 工具
- **Composables**：`useId`、`useFocusTrap`、`useRovingFocus`
- **文档**：Win95 桌面 MDX 文档站、Storybook
- **质量**：104+ Vitest / vitest-axe 用例

### Theme
- CSS 变量 `--w95-*`
- Tailwind 工具类 `w95-*`
- 统一 `.w95-focus` 点状焦点环

### Docs
- 修复 MDX 内容加载与窗口/对话框关闭
- 更大可读字号、安装指南、Changelog 与赞助信息

## 0.1.0

- pnpm monorepo 脚手架
- Button / Input / Checkbox / Window / Dialog
- Tailwind + shadcn 模式、a11y 测试基线
