### API

| 组件 | Prop | 说明 |
|------|------|------|
| `W95Tabs` | `modelValue?: string\|number` | 当前 tab（v-model） |
| `W95TabList` | — | `role=tablist`，方向键切换 |
| `W95Tab` | `value` 必填；`disabled?: boolean` | `role=tab` / `aria-selected` |
| `W95TabPanel` | `value` 必填 | `role=tabpanel`，仅显示匹配项 |

## Breadcrumb / Pagination

<div class="demo">
  <div class="demo-label">BREADCRUMB + PAGINATION</div>
  <W95Breadcrumb :items="crumbs" separator="›" />
  <div style="height:10px"></div>
  <W95Pagination v-model="page" :total="40" :page-size="10" />
  <p style="color:#fff;font-size:13px;margin:8px 0 0">page = {{ page }}</p>
</div>

### API — `W95Breadcrumb`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `items` | `{ label, href?, click? }[]` | `[]` | 面包屑 |
| `separator` | `string` | `">"` | 分隔符 |

最后一项为当前页（`aria-current="page"`）。

### API — `W95Pagination`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `number` | `1` | 当前页（v-model） |
| `total` | `number` | `0` | 总条数 |
| `pageSize` | `number` | `10` | 每页条数 |
