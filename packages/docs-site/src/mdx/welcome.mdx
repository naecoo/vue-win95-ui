# Welcome to **vue-win95**

这是一个用 **本组件库自己搭建** 的 Windows 95 风格文档站。

- 文档源文件：`MDX / Markdown + Vue 组件`
- 页面外壳：桌面、窗口、任务栏、Start 菜单
- 演示区：直接渲染 `vue-win95` 真实组件

<div class="demo">
  <div class="demo-label">LIVE DEMO</div>
  <W95Window title="My First VB4 Program" :width="280">
    <p style="margin:0 0 8px">Hello, documentation!</p>
    <W95Button default>OK</W95Button>
  </W95Window>
</div>

## 如何浏览

1. 在桌面 **单击 / 双击** 图标打开窗口
2. 或点击左下角 **Start** 从菜单打开
3. 任务栏可最小化 / 恢复窗口

## 技术要点

- Vue 3 + TypeScript
- Tailwind shadcn 模式 + `--w95-*` tokens
- WAI-ARIA APG 键盘与无障碍
- 像素字体 Pixelated MS Sans Serif（内置）
