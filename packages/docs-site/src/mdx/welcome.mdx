# vue-win95

## 组件库内容

约 **35 个** 组件，覆盖桌面应用常见界面：

| 分类 | 组件 |
|------|------|
| 基础 | Button, Input, Checkbox, Radio, Select, Slider, Switch, Avatar |
| 容器 | Window, Dialog, GroupBox, Accordion, StatusBar, Divider |
| 导航 | Tabs, MenuBar, Toolbar, Tree, Breadcrumb, Pagination, Splitter |
| 浮层 | Tooltip, Toast, Dropdown, ComboBox |
| 数据 | Table, SpinButton, DatePicker, ProgressBar |

另提供无障碍 composables：`useId` / `useFocusTrap` / `useRovingFocus`。

## 技术栈

- **Vue 3** + Composition API + `<script setup>`
- **TypeScript** 严格类型，完整 props / emits 推导
- **Tailwind CSS**（shadcn 模式）：`cn()` + design tokens
- **主题**：CSS 变量 `--w95-*`，可整体换肤
- **无障碍**：对齐 W3C APG，语义化 HTML + 键盘操作
- **视觉**：双层 inset 边框、像素字体、标题栏渐变
