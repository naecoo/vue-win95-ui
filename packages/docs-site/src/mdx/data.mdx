# Data 数据组件

Table · SpinButton · DatePicker · ProgressBar

## Table

<div class="demo">
  <div class="demo-label">TABLE</div>
  <W95Table
    v-model:selected-key="selected"
    :columns="columns"
    :rows="rows"
    :height="140"
    row-key="id"
  />
  <div style="display:flex;gap:8px;align-items:center;margin-top:8px">
    <W95Button @click="selected = null">Clear selection</W95Button>
    <span style="color:#fff;font-size:13px">selected = {{ selected }}</span>
  </div>
</div>

### API — `W95Table`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `columns` | `{ key, label, width? }[]` | — | **必填** 列定义 |
| `rows` | `Record<string, unknown>[]` | `[]` | 行数据 |
| `selectedKey` | `string\|number\|null` | `null` | 选中行 key（v-model） |
| `rowKey` | `string` | `"id"` | 行主键字段名 |
| `interactive` | `boolean` | `true` | 允许点击选中 |
| `height` | `number\|string` | — | 滚动区高度 |

| Event | Payload |
|-------|---------|
| `update:selectedKey` | 行 key 或 `null` |
| `select` | 整行对象 |

## SpinButton

<div class="demo">
  <div class="demo-label">SPIN BUTTON</div>
  <W95SpinButton v-model="copies" :min="0" :max="20" :step="2" label="Copies" />
  <p style="color:#fff;font-size:13px;margin:8px 0 0">copies = {{ copies }}</p>
</div>

### API — `W95SpinButton`

| Prop | Type | Default |
|------|------|---------|
| `modelValue` | `number` | `0` |
| `min` / `max` / `step` | `number` | `0` / `99` / `1` |
| `label` | `string` | 空 |
| `disabled` | `boolean` | `false` |

`role="spinbutton"` · ↑↓ 键 · ▲▼ 按钮 · min/max 钳制。

## DatePicker

<div class="demo">
  <div class="demo-label">DATE PICKER</div>
  <W95DatePicker v-model="date" label="Date" />
  <p style="color:#fff;font-size:13px;margin:8px 0 0">date = {{ date }} · 格式 YYYY-MM-DD</p>
</div>

### API — `W95DatePicker`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `string \| null` | `null` | ISO 日期 `YYYY-MM-DD`（v-model） |
| `label` | `string` | 空 | 标签 |

| Event | Payload |
|-------|---------|
| `update:modelValue` | `string \| null` |
| `change` | 同上 |

月历对话框：上月/下月、点选日期；输入框只读。

## ProgressBar

<div class="demo">
  <div class="demo-label">PROGRESS</div>
  <div style="max-width:360px;display:flex;flex-direction:column;gap:8px">
    <W95ProgressBar :value="progress" label="Install" />
    <W95ProgressBar :value="progress" segmented label="Segmented" />
  </div>
  <div style="margin-top:8px">
    <W95Button @click="progress = (progress + 15) % 120">+15%</W95Button>
  </div>
</div>

### API — `W95ProgressBar`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `value` | `number` | `0` | 当前值 |
| `max` | `number` | `100` | 最大值 |
| `segmented` | `boolean` | `false` | Win95 分段条 |
| `label` | `string` | `"Progress"` | `aria-label` |
