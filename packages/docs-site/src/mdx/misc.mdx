## 速查 API

| 组件 | 关键 Props | 无障碍 |
|------|-----------|--------|
| `W95Accordion` / `Item` | `modelValue`; `value`,`title` | `aria-expanded`, region |
| `W95Breadcrumb` | `items[]`, `separator` | nav + `aria-current` |
| `W95Pagination` | `modelValue`,`total`,`pageSize` | nav + `aria-current` |
| `W95Switch` | `modelValue`,`label`,`disabled` | `role=switch` |
| `W95Avatar` | `src`,`alt`,`initials`,`size` | title/alt |
| `W95GroupBox` | `legend` | fieldset + legend |
| `W95FieldRow` | `stacked` | 布局 |
| `W95StatusBar(Field)` | `grow` | `role=status` |
