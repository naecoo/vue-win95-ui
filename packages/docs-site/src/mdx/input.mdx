# Form Controls

文本框、下拉、滑杆、数字框等表单原语，全部基于语义 HTML + ARIA。

<div class="demo">
  <div class="demo-label">LIVE FORM</div>

## 设计说明

- 输入框使用 Win95 **field border**（双层 inset 阴影）
- 禁用态底色变为 `surface`，文字带高光 shadow
- Select / ComboBox 保持可访问名称（label 关联）
