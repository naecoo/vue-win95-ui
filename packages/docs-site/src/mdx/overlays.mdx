<script setup>
import { ref } from "vue";
import {
  W95Button,
  W95Tooltip,
  W95Toast,
  W95Dropdown,
  W95MenuItem,
  W95ComboBox,
} from "vue-win95";

const ddOpen = ref(false);
const driver = ref(2);
const toasts = ref([
  { id: 1, title: "Notepad", message: "Document saved.", duration: 0 },
]);
const options = [
  { value: 1, label: "MySQL ODBC 3.51 Driver" },
  { value: 2, label: "SQL Server" },
  { value: 3, label: "Access Driver" },
];

let n = 1;
function pushToast() {
  toasts.value = [
    ...toasts.value,
    { id: ++n, title: "System", message: `Hello #${n} from Windows 95.` },
  ];
}
</script>

# Overlays 浮层

Tooltip · Dropdown · ComboBox · Toast

## Tooltip

<div class="demo">
  <div class="demo-label">TOOLTIP</div>
  <div style="display:flex;gap:10px;flex-wrap:wrap;padding:20px 0">
    <W95Tooltip content="On top" placement="top"><W95Button>Top</W95Button></W95Tooltip>
    <W95Tooltip content="On bottom" placement="bottom"><W95Button>Bottom</W95Button></W95Tooltip>
    <W95Tooltip content="On left" placement="left"><W95Button>Left</W95Button></W95Tooltip>
    <W95Tooltip content="On right" placement="right"><W95Button>Right</W95Button></W95Tooltip>
  </div>
</div>

### API — `W95Tooltip`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `content` | `string` | 空 | 提示文案 |
| `placement` | `top\|bottom\|left\|right` | `top` | 相对位置 |
| `openDelay` | `number` | `200` | 悬停延迟 ms |

Slot：default 为触发元素。焦点进入也会显示。

## Dropdown

<div class="demo">
  <div class="demo-label">DROPDOWN</div>
  <W95Dropdown v-model="ddOpen" label="File">
    <W95MenuItem>New</W95MenuItem>
    <W95MenuItem>Open…</W95MenuItem>
    <W95MenuItem>Save</W95MenuItem>
    <W95MenuItem disabled>Print</W95MenuItem>
  </W95Dropdown>
  <p style="color:#fff;font-size:13px;margin:8px 0 0">open = {{ ddOpen }} · Esc / 外部点击可关闭</p>
</div>

### API — `W95Dropdown`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `boolean` | `false` | 菜单是否打开（v-model） |
| `label` | `string` | `"Menu"` | 触发按钮文案 |

| Slot | 说明 |
|------|------|
| default | 菜单项（建议 `W95MenuItem`） |

触发器：`aria-haspopup=menu`、`aria-expanded`；菜单内 ↑↓ / Home / End / Esc。

## ComboBox

<div class="demo">
  <div class="demo-label">COMBOBOX</div>
  <W95ComboBox v-model="driver" :options="options" label="Driver" />
  <p style="color:#fff;font-size:13px;margin:8px 0 0">driver = {{ driver }} · 输入可过滤</p>
</div>

### API — `W95ComboBox`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `string\|number\|null` | `null` | 选中值（v-model） |
| `options` | `{value,label,disabled?}[]` | `[]` | 选项 |
| `label` | `string` | 空 | 标签 |
| `disabled` | `boolean` | `false` | 禁用 |

| Event | Payload |
|-------|---------|
| `update:modelValue` | 选中值 |
| `change` | 选中值 |

## Toast

<div class="demo">
  <div class="demo-label">TOAST</div>
  <W95Button @click="pushToast">Show toast</W95Button>
  <W95Button style="margin-left:8px" @click="toasts = []">Clear all</W95Button>
  <W95Toast v-model="toasts" :duration="4000" />
</div>

### API — `W95Toast`

| Prop | Type | Default | 说明 |
|------|------|---------|------|
| `modelValue` | `W95ToastItem[]` | `[]` | 通知列表（v-model） |
| `duration` | `number` | `3000` | 自动关闭 ms；`0` 表示不自动关 |

```ts
interface W95ToastItem {
  id: string | number;
  title?: string;
  message: string;
  duration?: number; // 覆盖全局 duration
}
```

Teleport 到 `body`，`aria-live="polite"`，可手动关闭。
