# Accessibility — vue-win95

## Automated coverage

- Semantic HTML (`button` / `input` / `fieldset` / `nav` / `table`)
- Label association (Input, Select, Checkbox, Radio, Switch, Slider)
- Dialog: `alertdialog` + `aria-modal` + focus trap + Esc
- Tabs / Menu / Toolbar / Tree: roving tabindex + arrow keys
- Combobox: `combobox` / `listbox` / `option` + keyboard
- Table: focusable helper, arrow-key selection, `aria-sort`
- Progress / Spin: `aria-valuenow` / `min` / `max`
- vitest-axe suite in CI

## Manual screen reader checklist

| Scenario | Check |
|----------|-------|
| Dialog open | Focus moves into dialog; title is announced; Esc restores focus to trigger |
| ComboBox | Announced as combobox; filtering; Up/Down and `aria-activedescendant` |
| Tabs | Tab selected is announced; Left/Right switches panels |
| Tree | Expand/collapse `aria-expanded`; selection `aria-selected` |
| Table | Selection changes are perceivable |
| Toast / Notification | `aria-live=polite` announces the message |
| Icon-only buttons | `aria-label` announced |

## Contrast notes (WCAG AA)

| Pair | Expected |
|------|----------|
| `#222` text on `#c0c0c0` surface | Pass |
| `#fff` title on `#000080` to `#1084d0` gradient | Spot-check the light-blue end |
| Disabled `#808080` on `#c0c0c0` | Relaxed for disabled controls |
| Selected row `#fff` on `#000080` | Pass |

## Focus visibility

Use `.w95-focus` (1px dotted inset) on every interactive control.
