# Accessibility — vue-win95-ui

## Automated coverage

- 语义 HTML（`button` / `input` / `fieldset` / `nav` / `table` / `ul[role=tree]`）
- 标签关联（Input / Textarea / Select / Checkbox / Radio / Switch / Slider；`W95FormItem` 会自动接 `for`）
- Dialog：默认 `role="dialog"`，确认类用 `alertdialog`；`aria-modal`、焦点陷阱、Esc 只关最上层、滚动锁在卸载时还原
- Tabs：`tablist` / `tab` / `tabpanel` 三角关联，方向键 roving tabindex，Enter/Space 选中（挂载时不抢焦点）
- MenuBar：`menubar`、一次只展开一个、悬停切换、点击外部或 Esc 关闭
- Tree：`tree` / `treeitem` / `group`；无选中时首个节点仍可 Tab 进入，↑↓ Home End 移动，←→ 展开收起，typeahead
- ComboBox：`combobox` / `listbox` / `option` + `aria-activedescendant`，点外部收起，`clearable` 有可访问名
- Table：`aria-sort`、行 `aria-selected`、`aria-activedescendant` 指向键盘焦点行、`aria-busy` 加载态
- Progress / Spin：`aria-valuenow` / `min` / `max`
- 浮层统一：定位翻转与夹缝、teleport、外部点击与 Esc 由同一套内核处理
- vitest-axe 用例覆盖各组件的默认渲染，CI 会跑

## Manual screen reader checklist

| Scenario | Check |
|----------|-------|
| Dialog open | 焦点移入弹窗；标题被播报；Esc 只关最上层并回到触发元素 |
| ComboBox | 播报为 combobox；过滤时 `aria-activedescendant` 跟随；Esc 收起 |
| Tabs | 选中态被播报；←→ 移动焦点；Enter/Space 切换面板 |
| Tree | 展开收起 `aria-expanded`；选中 `aria-selected`；无选中时可 Tab 进入 |
| MenuBar | `aria-haspopup` / `aria-expanded`；Esc 关闭并回到顶层项 |
| Table | 选中行变化可感知；排序状态由 `aria-sort` 播报 |
| Toast / Notification | `aria-live=polite` 播报消息 |
| Icon-only buttons | 有 `aria-label`，且随 `locale` 切换语言 |

## Contrast notes (WCAG AA)

| Pair | Expected |
|------|----------|
| `#222` text on `#c0c0c0` surface | Pass |
| `#fff` title on `#000080` to `#1084d0` gradient | 浅蓝端需要抽查 |
| Disabled `#808080` on `#c0c0c0` | 禁用控件放宽 |
| Selected row `#fff` on `#000080` | Pass |
| Error text `#a4262c` on `#c0c0c0` | Pass |

## Focus visibility

统一用 `.w95-focus`（1px dotted inset）。Input / Textarea / Select / SpinButton / 浮层触发项都已接上。
