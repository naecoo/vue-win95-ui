# Accessibility checklist — vue-win95

## 组件级（自动化已覆盖）

- [x] 语义 HTML（button/input/fieldset/nav/table）
- [x] label 关联（Input/Select/Checkbox/Radio/Switch/Slider）
- [x] Dialog：`alertdialog` + `aria-modal` + focus trap + Esc
- [x] Tabs/Menu/Toolbar/Tree：roving tabindex + 方向键
- [x] Combobox：combobox/listbox/option + 键盘
- [x] Table：可聚焦 + 方向键选择 + `aria-sort`
- [x] Progress/Spin：aria-valuenow/min/max
- [x] vitest-axe 扫描（122 tests）

## 手动读屏器清单（发布前建议）

### NVDA + Chrome / VoiceOver + Safari

| 场景 | 检查项 |
|------|--------|
| Dialog 打开 | 焦点进入对话框；朗读标题；Esc 关闭后焦点回到触发器 |
| ComboBox | 朗读「combobox」；输入过滤；↑↓ 选项与 activedescendant |
| Tabs | 「tab selected」；←→ 切换时面板更新 |
| Tree | 展开/收起 `aria-expanded`；选中 `aria-selected` |
| Table | 行选择变化是否可感知（必要时补 `aria-live`） |
| Toast/Notification | `aria-live=polite` 是否朗读 message |
| 仅图标按钮 | `aria-label` 是否朗读（Window 控制钮、关闭钮） |

## 对比度备注（WCAG AA）

| 组合 | 预期 |
|------|------|
| `#222` 文字 on `#c0c0c0` surface | 通过 |
| `#fff` 标题 on `#000080→#1084d0` 渐变 | 蓝色端需抽查（浅蓝端对比度较低） |
| 禁用 `#808080` on `#c0c0c0` | 允许放宽（disabled 控件） |
| 选中行 `#fff` on `#000080` | 通过 |

工具：WebAIM Contrast Checker / axe DevTools。

## 焦点可见性

统一使用 `.w95-focus`（1px dotted inset）。新交互控件请套用该 class。
